his project aims to detect fake news articles using Machine Learning (ML) and Natural Language Processing (NLP). The system classifies news articles as real or fake based on their content, leveraging various ML models, including Logistic Regression, Support Vector Machine (SVM), Random Forest, and Decision Trees.

Features
Data Preprocessing: Cleans and prepares news data for model training by handling missing values, text normalization, and feature extraction.
Model Comparison: Implements and compares multiple machine learning models (Logistic Regression, SVM, Random Forest, Decision Tree) to determine the most accurate classifier for fake news detection.
